## Code with reveals

Mark a line with `// [!]` and it stays hidden until you press next. Pressing
next reveals that line plus everything up to the next mark — so ask the room
first, then walk the code forward.

```cpp
int sum = 0;                     // [!]
for (int i = 0; i < n; i++) {    // [!]
    sum += a[i];                 // [!]
}
```

Every code block gets a Copy button for students, so the snippet has to compile
on its own.
